🖱️ Technical Details

💻 Physical Mouse Input Only
Doomsday operates exclusively through physical mouse and keyboard input due to Windows OS and Unity game limitations. This design choice ensures reliability and compatibility.

Future Possibilities

While not currently available, we're exploring additional platforms:

  • Emulator Support: A separate implementation for emulator-based gameplay (may come later)
  • Mobile Ports: Android and iOS versions are technically challenging but under consideration
  • Feature Priority: If mobile versions release, farming and healing will be prioritized first, though some advanced features may have limited availability initially

📺 Resolution Support

Windows can be resized freely for flexibility. However, individual macros currently target specific 16:9 resolutions for reliable automation. More resolutions are continuously being added as the tool evolves.

🛡️ Security & Safety

🔐 Antivirus Scanning

Because Doomsday performs real mouse and keyboard automation, Windows Defender and antivirus software may inspect it more closely than ordinary applications. This does not indicate malicious behavior.

We encourage you to verify every release yourself using VirusTotal. Scan link:

🛡️ VirusTotal - Verify Downloads

🔒 Windows Smart App Control

Windows 11 Smart App Control may prevent unsigned applications from launching. If you encounter this, follow these steps:

  1. Open Windows Security
  2. Navigate to App & Browser Control
  3. Find Smart App Control
  4. Disable Smart App Control if you trust this application

⚠️ Only disable this if you're confident about the source. We recommend using Sandboxie for additional safety when running untrusted software.
